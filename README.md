# Fleet Project

Учебный проект на Python: модель автопарка с использованием ООП, наследования и JSON.

## Что делает

Программа моделирует автопарк транспортной компании:

- Хранит машины (легковые и грузовые) и водителей.
- Позволяет закреплять водителя за машиной и освобождать её.
- Ищет машины по марке.
- Показывает свободные машины.
- Сохраняет и загружает данные в формате JSON.

## Классы

- **`Vehicle`** — базовый класс: `brand`, `model`, `year`, `mileage`, `available`.
- **`Car(Vehicle)`** — легковая машина: `seats`, `fuel_type`.
- **`Truck(Vehicle)`** — грузовая машина: `capacity_kg`, `axles`.
- **`Driver`** — водитель: `name`, `license_number`, `assigned_vehicle`.
- **`Fleet`** — автопарк: управляет списками машин и водителей.

## Что использовано

- **ООП**: классы, наследование, инкапсуляция, полиморфизм.
- **`@property` и `@x.setter`** — для валидации значений при присваивании.
- **Магические методы**: `__str__`, `__repr__`, `__eq__`, `__len__`.
- **`super().__init__()`** — вызов родительского конструктора.
- **`isinstance`** — проверка типов.
- **`try / except ValueError`** — обработка ошибок валидации.
- **Работа с файлами**: `json.dump`, `json.load`.
